# 夜班档案 · 狐狸警官

**走进奇幻城镇，用询问和物证拼出案件真相。**

第三人称浏览器 AI 探案游戏原型。玩家在室内场景调查案件，与各自掌握部分事实的 NPC 对话，搜集物证并提交结案。

## 玩法循环

进入现场 → 观察与搜证 → 询问 NPC → 交叉验证线索 → 判断嫌疑人 → 提交结案。

## 核心设计

- 三种场景及简单、中等、困难三档难度，NPC 数量分别为 3、4、6。
- AI 案件生成与结构校验，约束案件角色和证据关系。
- NPC 只持有部分事实，鼓励玩家比较口供与物证。
- 物证搜集和结案判定组成完整调查流程。
- 无模型配置时可使用本地演练案件。

技术栈：JavaScript · Three.js · Node.js · DeepSeek API。

## 当前阶段

本机浏览器功能原型，具有产品需求文档与流程验证。场景美术和实际游戏体验以当前原型为准。

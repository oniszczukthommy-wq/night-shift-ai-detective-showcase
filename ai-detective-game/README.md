# 夜班档案 · 狐狸警官

本机浏览器探案游戏。最新确认：TUNIC 为主要视觉与建模参考，Escape Simulator 为 NPC、陈设和搜证交互的辅助参考；故事改为奇幻城镇，玩家为狐狸警官。

## 打开游戏

双击 `启动游戏.command`，会自动启动本机服务并打开 Chrome（未安装时使用默认浏览器）。启动后可以关闭终端窗口，服务会继续运行；电脑重启后再次双击即可。游戏地址为 <http://127.0.0.1:4173>。Safari、Chrome、Edge、Firefox 需要启用 WebGL 2；当前地址仅供这台 Mac 使用。启动日志保存在已被 Git 忽略的 `.runtime/server.log`。

## 操作

- WASD／方向键：按屏幕方向移动；点击地面或目标可寻路走近，桌柜会阻挡移动。
- E：与附近人物交谈、打开柜门或抽屉、拿起物品检查。
- 检查物品时拖动旋转、滚轮缩放，点击“拿取并记入证物”收入证物栏。
- Tab／调查手册：查看人物和证物。点击已取得证物可再次检查。
- 询问时可文字输入，或按住 V 说话、松开发送；浏览器不支持识别时使用文字。
- H：申请提示；“提交结案”勾选嫌疑人、动机、方式和支持物证。结论错误可以继续调查，正确后回顾完整案件故事。

## 模型与参考

此版本直接转换了用户已安装参考游戏与 REA 归档中的选定几何、UV、材质纹理和人物骨骼。狐狸、标题长剑、石拱门、桌凳、宝箱取自 TUNIC；NPC 人物部件和四件证物几何取自 Escape Simulator。不是原作完整工程或全套动画的恢复。

浏览器模型在 `public/assets/reference/`，来源记录在 `manifest.json`，转换脚本在 `scripts/`。房间在 Three.js 中组合，使用斜俯视相机、阴影、柔焦与光晕。三种房间、家具镜像布局和场景细节按种子变化。

## AI 与语音

真实 DeepSeek 接入通过本机 Node 服务代理。密钥仅从 `.env.local` 读取，已被 Git 忽略。案件 JSON 校验人数、物证数量、凶手在场和指向关系；NPC 仅收到自身事实、与自己的对话历史和已找到的证物。当前四件物证固定为茶杯、纸张、铜钥匙、药剂瓶，AI 生成与这些实物相符的案件。

语音识别依浏览器和系统而异；NPC 朗读和结案故事使用浏览器语音合成。还需用户实际麦克风验收。未采购额外语音服务。

模型单次进程最多 250 次请求，网络中断至多重试一次；这不是人民币硬上限。可在 DeepSeek 控制台查看余额。模型不可用会提示并载入本地演练案件，不伪装为在线生成。
